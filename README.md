# Walmart Customer Retention Analysis

## Project Overview

Walmart Customer Retention Analysis is an interactive Power BI project focused on understanding customer behavior, churn, repeat purchases, loyalty program performance, promotions, store/channel performance, and Customer Lifetime Value (CLV).

The project transforms customer and transaction data into interactive dashboards that provide business insights and actionable recommendations for improving customer retention and engagement.

## Objectives

- Analyze customer churn and retention patterns.
- Identify repeat purchase behavior across customer segments.
- Evaluate loyalty program and promotion performance.
- Analyze store and channel performance.
- Calculate and segment customers based on Customer Lifetime Value (CLV).
- Identify high-value customers and high-churn segments.
- Provide actionable recommendations for improving retention.

## Dashboard Pages

### 1. Executive KPI Dashboard

Key metrics and overall customer retention performance.

- Churn Rate
- Repeat Customers
- Customer Lifetime Value (CLV)
- Customer Funnel
- Churn Rate by Region
- Interactive Slicers

### 2. Loyalty & Promotion Impact

Analyzes the relationship between promotions, loyalty tiers, and customer engagement.

- Promotion Applied %
- Average Purchase Amount by Promotion
- Churn Rate by Loyalty Tier
- Points Earned vs Redeemed
- Loyalty and promotion insights

### 3. Store & Channel Insights

Analyzes store and channel performance in relation to customer retention.

- Average Transaction Amount by Store Type
- Churn Rate by Store Type
- Opening Year vs Transaction Amount
- Channel and store-level insights

### 4. Customer Segmentation

Analyzes customer purchasing behavior and customer segments.

- Average Purchase Frequency by Age Group
- Customer Segments by Purchase Tier
- Average Purchase Frequency by Region
- CLV by Loyalty Tier
- CLV by Region

### 5. Customer Lifetime Value (CLV) Analysis

Analyzes customer value and identifies high-value and low-value customer segments.

- Overall CLV
- High CLV vs Low CLV segmentation
- CLV by Loyalty Tier
- CLV by Region

## Key Findings

- Overall customer churn rate is approximately 50%.
- The West region shows the highest churn rate in the analysis.
- There are 210 repeat customers in the analyzed dataset.
- Average Customer Lifetime Value is approximately 30.55K.
- Approximately 48% of transactions used promotions.
- Premium and Plus loyalty tiers show high reward-point activity.
- Premium customers generate the highest CLV among loyalty tiers.
- Store types show differences in average transaction amount and churn rate.

## Recommendations

1. **Prioritize High-Value Customers**
   
   Focus retention efforts on high-CLV customers and Premium/Elite loyalty members.

2. **Improve High-Churn Segments**
   
   Develop targeted retention campaigns for regions and store types with higher churn rates.

3. **Strengthen Loyalty Program Engagement**
   
   Improve reward redemption opportunities, exclusive benefits, and targeted loyalty promotions.
